# Официальные пакеты и модули

Начиная с `0.10.x`, ядро `jarvisd` включает базовую работу колонки (микрофон, локальный детектор «Джарвис», звук, подсветку, кнопки, связь с Алисой, память, веб-панель) и **5 встроенных голосовых/AI-провайдеров**: `ChatGPT` (аккаунт), `OpenAI`, `Gemini`, `Grok` и `ElevenLabs`. Ставить их отдельными плагинами больше не нужно.

Остальные официальные возможности устанавливаются отдельными пакетами из мастера или на странице **Подключения → Плагины**:

- **Официальные Lua-плагины:** `weather` (Погода Open-Meteo), `currency` (Курсы валют ЦБ РФ / НБ РБ), `dice` (Монетка и кубик), `yandexhome` (Яндекс Умный дом).
- **Официальные Rust-пакеты (`arm64` / `armv7`):** `homeassistant`, `smartlife`, `xiaomi`, `vpn`, `youtube`, `training` (Обучение слова).

Панель скачивает выбранный архив (для Rust — `plugin-<id>-<arch>.zip` из релиза с проверкой `SHA256SUMS`), запускает плагин и сохраняет его пользовательские данные отдельно при обновлениях. При удалении процесс останавливается, бинарник и данные освобождают место на флешке. Для смены состава плагинов перезагружать ядро не нужно (кроме пакетов с `"reboot_on_update": true`).

Команда `jarvis core-info` показывает версию, архитектуру и список встроенных при компиляции модулей (у штатной сборки он пустой). Установленные плагины перечислены в `/api/plugins`.
