# YaJarvis 0.9.83-rs

- Rust-установщик для Windows, Linux и macOS. Для установки нужен Android Platform Tools.
- Rust-служба запуска проверяет SHA-256 и готовность ядра, при ошибке старта возвращает предыдущую сборку.
- Ядро обновляется из Rust-релизов. Обновление проверяет архитектуру и сохранение установленных модулей.
- Подключения, музыка, VPN и обучение слова работают как Rust-модули. Дополнительные сценарии работают на Lua.
- Go-код, SDK нативных Go-плагинов и исполняемые JS-плагины удалены.
