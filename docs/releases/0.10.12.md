# YaJarvis 0.10.12

- Восстановлен анонимный счётчик установок в Rust-ядре: колонки снова отмечаются в служебном релизе `stats` и появляются в графике версий в README (сохранён прежний файл отметки `/data/.yajavis-counter`, чтобы уже посчитанные колонки с `0.9.x` не дублировались).
- Добавлена поддержка обновлений из панели и ночного автообновления для колонок, которые обновились с Go-версии `0.9.x` поверх старого `jarvisd.sh` без повторного запуска установщика.
