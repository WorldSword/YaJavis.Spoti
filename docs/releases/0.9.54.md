## Пылесос без Home Assistant

### Исправления

- **«Включи пылесос» больше не уходит в выключенный Home Assistant.** Быстрая команда для пылесоса срабатывала, если у Джарвиса записан адрес Home Assistant, даже при снятой галочке. Теперь она работает, только когда HA включён и отвечает. В остальных случаях пылесос включается через Xiaomi Home или Smart Life.
- **Ошибки больше не попадают в общую память.** Ответы вроде «сервис недоступен» не запоминаются, иначе модель повторяла их вместо того, чтобы заново попробовать выполнить команду.

### Установка

Колонки с автообновлением обновятся ночью сами. Вручную: панель → «Безопасность» → «Проверить» → «Обновить».
