# YaJarvis 0.10.15

- Восстановлена кнопка «Проверить связь» (`POST /api/test/net`): проверяются только настроенные провайдеры (включая вход в ChatGPT по подписке и запасной тест VPN, если сервисы ещё не добавлены), с понятными статусами и отображением ошибок вместо «Неизвестный API».
- Перенесено создание и удаление своих голосов GPT-Live по описанию (`POST /api/voices`, `DELETE /api/voices`).
- Исправлен каталог официальных плагинов: колонка берёт список из ветки `main` и не предлагает уже встроенные в ядро голосовые движки (`chatgpt`, `openai`, `gemini`, `grok`, `elevenlabs`).
- При добавлении первого API-ключа или входе в ChatGPT пустой голосовой движок активного ассистента выбирается автоматически, а при невыбранном движке выводится точная подсказка «Выберите голосовой движок в настройках ассистента».
- В плагине VPN (`0.3.4`) расширена совместимость с VLESS-ссылками из подписок: поддерживаются `fp=edge/safari/ios/android/random/randomized`, `fp` при обычном `security=tls` и `alpn=h2` / `http/1.1` / `h2,http/1.1` для TCP/REALITY.
- Улучшено предпрослушивание голосов в настройках (по мотивам PR #31 от @SHAREN): индикация этапов на кнопке и в уведомлении, моментальная отмена зависшей или устаревшей сессии при переключении голоса и диагностика уровней PCM без записи речи.
