# YaJarvis 0.10.0

- Чистая установка содержит базовую прошивку. При первом входе панель предлагает выбрать официальные плагины, настроить подключения и выбрать голосового ассистента.
- Каждое подключение скачивается отдельно. Удаление в «Подключениях» останавливает плагин и освобождает место на флешке. Основная прошивка продолжает работать.
- Поддерживаются плагины на Lua и независимые исполняемые пакеты для архитектуры колонки.
