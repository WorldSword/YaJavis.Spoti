# YaJarvis 0.9.88-rs

- Rust-плагины можно распространять отдельными ZIP для архитектуры колонки. Для установки и удаления не требуется менять ядро.
- SDK Rust-пакетов поддерживает команды, инструменты, настройки и текстовые модели.
- Каталог оставляет универсальный Lua API для собственных подключений.
