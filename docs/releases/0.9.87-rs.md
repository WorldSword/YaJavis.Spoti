# YaJarvis 0.9.87-rs

- Lua-плагины загружаются при установке из исходников соответствующей версии. Каталог хранится в памяти, архивы плагинов не вшиваются в ядро.
- Сборка выпускается с одним выбранным списком Rust-модулей. Колонка проверяет точный список при обновлении и удаляет старое ядро после успешного перезапуска.
- ChatGPT готовит авторизацию и WebRTC параллельно. В звонок передаётся более короткий буфер перед словом активации.
