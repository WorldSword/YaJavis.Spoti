## Следующее видео готово заранее, автообновление по умолчанию

- **Следующее видео подбирается в фоне.** Пока играет ролик из вашей истории YouTube, Джарвис заранее подбирает, что включить дальше: рекомендации под этим видео, а если их нет — похожее. Кнопка «Следующий» в плеере работает сразу, а в конце ролика предложение «Послушаем?» звучит без паузы.
- **Автообновление включено по умолчанию.** Новые версии ставятся сами ночью, с 3 до 6, когда колонка молчит. Колонки, которые уже стоят, тоже переходят на автообновление один раз. Если выбрать «Вручную» на странице «Безопасность», выбор сохранится.

### Установка

Колонки обновятся сами. Вручную: панель → «Безопасность» → «Проверить» → «Обновить».
