## Знакомство с YaJarvis начинается с установки

Новый установщик в стиле веб-панели: больше воздуха, мягкие карточки и тёплый оранжевый акцент. Пока файлы переносятся на колонку, можно посмотреть панель и узнать, что умеет помощник.

### Что нового

- **Обновлённый установщик** для Windows, macOS и Linux: понятные шаги, крупные элементы и отдельная область знакомства с проектом.
- **Скриншоты во время установки.** Четыре экрана с пояснениями про диалог, подключения, ассистентов и графики. Показ можно переключать вручную или поставить на паузу.
- **YaJarvis в боковой панели.** Новое название в левом верхнем углу.
- **Аккуратная просьба поддержать проект.** Компактная карточка GitHub с одной ссылкой и крестиком; закрытие запоминается.
- **Авторы и благодарности.** В README появились аватары и ссылки на авторов проектов, которыми вдохновлялся YaJarvis. Отдельно отмечен дизайн dimap / yapanel.

### Исправления

- Версия отображается с одним префиксом `v`.
- Повторные проверки сборки изолированы от фоновой подготовки музыки.

### Как обновиться

В панели откройте **Безопасность → Обновления → Проверить → Обновить**. Настройки и подключения сохраняются; Джарвис перезапустится. После обновления обновите страницу браузера.

Для первой установки скачайте подходящий `JarvisSetup` ниже. Если обновляете колонку файлом, используйте `jarvisd-arm64` или `jarvisd-armv7`. Загрузки проверяются по `SHA256SUMS`.
