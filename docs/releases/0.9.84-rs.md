# YaJarvis 0.9.84-rs

- Lua API для собственных текстовых моделей. Плагин можно выбрать у ассистента для переписки и классического голосового режима.
- Новые записи обучения сжимаются без потерь. Старые записи можно компактировать через `POST /api/train/records/compact`. Прослушивание и экспорт по-прежнему отдают WAV.
- Убрана дополнительная реализация ZIP-сжатия из сборки колонки.
