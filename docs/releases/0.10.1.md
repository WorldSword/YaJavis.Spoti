# YaJarvis 0.10.1

- В «Колонка → Слово активации» можно выключить быстрые реплики «слушаю» и «угу». Вопрос можно начать сразу, пока звучит отклик.
- Gemini Live учитывает настройку поиска в интернете. Текстовый Gemini повторяет запрос способом авторизации Live, если Google отклонил передачу ключа в заголовке.
- «Стоп», «заткнись» и похожие команды завершают разговор. Музыка продолжает играть.
- При заполнении лимита 10 самых старых непроверенных записей обучения выгружаются одним ZIP в подключённое облако. Колонка удаляет их после подтверждения загрузки.
- Исправлена установка на станции с разделом `/etc` только для чтения. Добавлена поддержка профиля Firefox для VLESS REALITY и сборка с PowerShell. Спасибо [i7d3v3l0p3r](https://github.com/i7d3v3l0p3r).
