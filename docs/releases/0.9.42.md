## YaJarvis — голосовой помощник на вашей Станции

Локальная активация, выбор AI-движка, музыка и умный дом в одной веб-панели. Эта версия добавляет автоматическое определение моделей и готовую установку из GitHub Releases.

### Что нового

- **Автоопределение колонок.** Лайт, Лайт 2, Мини разных поколений, Миди, Стрит и другие Станции определяются по идентификаторам платы.
- **Проверка прошивки.** Установщик подбирает программу и библиотеку микрофона по ARM ABI, проверяет необходимые компоненты и объясняет несовместимость.
- **Обновления из Releases.** Загрузка подходящего файла с проверкой SHA-256.
- **README со скриншотами**, установка одной командой и сведения об авторах сторонних проектов. Дизайн панели вдохновлён dimap / yapanel.

### Исправления

- Быстро сохранённые записи обучения получают уникальные имена и не перезаписывают друг друга.
- Обновление через установщик использует временную память вместо второй полной копии программы на небольшом разделе колонки.

### Установка и обновление

Скачайте установщик для Windows, macOS или Linux. Для уже установленного YaJarvis откройте **Безопасность → Обновления**.

Полный голосовой тракт проверен на Лайт первого поколения. На других определяемых моделях поддержка экспериментальная; Android-модели пока не устанавливаются.
