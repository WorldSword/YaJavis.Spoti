## Первый публичный релиз YaJarvis

Джарвис для Яндекс Станции с веб-панелью, музыкой и умным домом — без отдельного сервера.

### В этом релизе

- Установщики для **Windows x64, macOS Intel / Apple Silicon и Linux x64 / ARM64**.
- Голосовые движки OpenAI, Gemini, Grok и ElevenLabs; профили с собственными голосами и характерами.
- YouTube, интеграции умного дома, настройки громкости и подсветки.
- Обновления из GitHub Releases с проверкой контрольной суммы.
- Стандартные начальные настройки: город не задан, часовой пояс UTC, личные аккаунты не подключены.

### Начать пользоваться

Откройте [инструкцию установки](https://github.com/newfpv/YaJarvis#установка), скачайте подходящий `JarvisSetup` и выберите колонку в браузере. Нужны root-доступ и ADB по сети.

Проверено на Яндекс Станции Лайт первого поколения. Более новые версии доступны в [последнем релизе](https://github.com/newfpv/YaJarvis/releases/latest).
