# Rust-пакеты

Rust-пакет содержит исполняемый файл и манифест. Он устанавливается из ZIP или из релиза репозитория в «Подключениях». Джарвис запускает его отдельным процессом. При отключении процесс завершается, при удалении его бинарник и данные освобождают место на флеше. Пакет работает с правами службы Джарвиса, поэтому устанавливайте только пакеты, издателю которых доверяете.

## Собрать пакет

1. Добавьте `jarvis-plugin-sdk` с feature `process` и реализуйте `Plugin`. В `main` вызовите `process::serve`. См. [пример process_echo](../jarvis/plugin-sdk/examples/process_echo.rs).
2. Соберите исполняемый файл для Linux с musl. Для ARM64 используйте `aarch64-unknown-linux-musl`, для ARMv7 используйте `armv7-unknown-linux-musleabihf`.
3. Положите бинарник и `plugin.json` в корень одного ZIP. Архив можно загрузить через веб-панель. Для каталога GitHub опубликуйте `jarvis-plugin-arm64.zip` или `jarvis-plugin-armv7.zip` в релизе репозитория с темой `yajarvis-plugin`.

```json
{
  "id": "native-echo-package",
  "name": "Rust Echo",
  "version": "1.0.0",
  "kind": "rust",
  "arch": "arm64",
  "api": 1,
  "category": "assistant",
  "main": "process_echo",
  "provides": ["llm"]
}
```

SDK передаёт в `Init` настройки из манифеста и сведения о колонке. Рабочая папка процесса выделена для его данных. Обработайте `command` для быстрой команды, `tool` для объявленных инструментов и `llm.chat` для [текстовой модели](LUA.md#своя-текстовая-модель). Для диагностики используйте stderr. Stdout используется для обмена с ядром.

## Встраивание в ядро

Для тесной связи с оборудованием и зависимостями ядра также можно собрать Rust-библиотеку внутри него.

1. Добавьте зависимость от `jarvis-plugin-sdk` в свой crate.
2. Реализуйте `Plugin::request` и экспортируйте `Registration` с манифестом и функцией создания экземпляра.
3. Добавьте свой crate в зависимости `jarvis/native-plugins/Cargo.toml` и регистрацию в список `PLUGINS`. В манифесте `kind` — `module`, значения `id`, `main` и единственного элемента `provides` совпадают.
4. Соберите ядро с feature `native-plugins`, сохранив текущие Cargo features колонки. Для добавления модуля передайте бинарник в `PUT /api/update/upload?module=<id>` из авторизованной панели. Модуль включится при запуске новой сборки.

```sh
cd jarvis
cargo run -p jarvis --features native-plugins,jarvis-native-plugins/example -- core-info
```

Команда добавляет только для проверки [Rust Echo](../jarvis/native-plugins/src/example.rs). В штатной сборке список дополнительных регистраций пуст.

Контекст SDK даёт папку данных, настройки, сведения о колонке, озвучку и вызовы объявленных сервисов ядра. Для быстрой команды обработайте `command`. Для инструментов верните схемы из `tools` и обработайте запрос `tool` с полями `name` и `arguments`. Для текстовой модели выставьте `chat: true` и обработайте `llm.chat` по [тому же контракту, что и Lua](LUA.md#своя-текстовая-модель). При отключении ядро отменяет ожидающие вызовы и вызывает `stop`. Фоновые задачи завершает сам модуль.

Установка через панель включает нативный код этой сборки. При удалении освобождаются файлы модуля и его данные. Чтобы убрать также машинный код и зависимости с флеша, пересоберите ядро без модуля и установите получившийся бинарник. Прямой доступ к внутренним Rust-типам ядра меняется между версиями.
