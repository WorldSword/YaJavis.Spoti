# Spotify в YaJavis

Джарвис не играет Spotify сам. Музыку воспроизводит [Soloist](https://github.com/Horohi/soloist-station-lite) (Spotify Connect на колонке), который вы ставите отдельно. YaJavis находит его, передаёт ему запрос и показывает, что играет, в панели. Движок Soloist принадлежит Spotify AB, его нет в этом репозитории.

## Что нужно

- Spotify **Premium**.
- Soloist на колонке: `yam install horohi/soloist`, затем `soloist setup`. Либо ручная установка по инструкции Soloist (в `/data/opt/soloist`).
- API-ключ Soloist: `developer.spotify.com/dashboard/soloist`. Для голосового поиска нужен ещё Client ID и Secret приложения Spotify Developer (по желанию, если свои).
- Папку Soloist Джарвис ищет в `/data/yam/share/horohi.soloist`, затем в `/data/opt/soloist`. Другое место задаётся переменной `SOLOIST_DIR`.

## Установка Soloist

Soloist ставится установщиком Джарвиса (JarvisSetup, шаг «Почти готово» → «Spotify через Soloist»): вставьте API-ключ (имя устройства и Client ID/Secret по желанию). Установщик на вашем компьютере скачает официальный релиз `soloist-station-lite.tar.gz` с GitHub автора (Horohi), сверит SHA-256, если GitHub его отдаёт, передаст на колонку по ADB и запустит `install.sh`. Затем колонка перезагрузится вместе с Джарвисом. Если Soloist поставить не вышло, Джарвис всё равно установлен, а причина видна в журнале установщика. Повторный запуск установщика обновляет Джарвиса и ставит Soloist, настройки сохраняются.

Установщик Soloist сам проверяет, что ядро колонки aarch64 (Станция 2 подходит), и ему нужно около 40 МБ свободно в `/data`.

## Настройка в панели

«Подключения → Spotify»: статус (найден, играет), имя устройства, API-ключ, при желании Client ID и Secret. Кнопка «Сохранить» отправляет только изменённые поля, ключи показываются маской. Soloist читает ключи только при старте, поэтому после «Сохранить» Джарвис перезапускает его сам (через YAM или `soloist-cli restart`). Если перезапуск не удался, карточка скажет об этом, а кнопка «Перезапустить Soloist» повторит его.

## Голосом

- «Джарвис, включи Imagine Dragons в Spotify»
- «Джарвис, включи в Спотифай», «в Спотик» — продолжить
- «пауза», «продолжай», «следующее», «предыдущее», «что играет» — управляют Spotify, пока он играет
- Запуск Spotify останавливает YouTube Джарвиса и ставит на паузу Алису, если играет она.
- Триггер — только слово Spotify/Спотифай/Спотик. Обычное «включи …» по-прежнему идёт в YouTube.

## Чек-лист приёмки на Станции 2

Проверено только на уровне тестов с подставным Soloist. Формат `now --json` взят из документации, не с живой колонки.

1. Soloist запускается, колонка видна в списке устройств Spotify.
2. «Джарвис, включи X в Spotify» играет на колонке; в панели видны обложка и название.
3. «пауза», «следующее», «что играет» управляют Spotify.
4. Сенсорные кнопки: кто реагирует, нет ли двойного нажатия (мост Soloist и `buttons.go`).
5. Команда Джарвиса Алисе (`alice_command`) не перехватывается мостом Soloist как запрос в Spotify.
6. Вывод `soloist ctl -w 127.0.0.1:9090 now --json` во время игры приложить к отчёту: по нему сверяются фикстуры `spotifynow_test.go`.
