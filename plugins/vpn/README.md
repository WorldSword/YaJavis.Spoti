# VPN (VLESS)

Официальный нативный плагин YaJarvis, начиная с ядра 0.9.69. Xray находится в отдельном процессе.
Если VPN не нужен, плагин не требуется и его код не входит в ядро.

Установите «VPN (VLESS)» на странице «Плагины», затем добавьте ссылку в «Подключения → VPN».
Там же выбирается маршрут каждого сервиса. Настроенный в предыдущей версии VPN переносится
автоматически: старое ядро ставит плагин из целевого релиза перед обновлением.

Поддерживаются VLESS TCP/WebSocket с TLS/REALITY и проверка несовместимого `flow`, как до переноса.
Ограничения ссылок проверяются самим плагином. Если плагин отключён, удалён или упал,
подключения с выбранным VPN возвращают ошибку; напрямую они не переключаются.

Данные соединения передаются по stdin/stdout между ядром и плагином. Локальный SOCKS5 слушает
loopback и требует одноразовый пароль; имя целевого сервера передаётся в туннель без локального DNS.
Ссылка остаётся в защищённом файле настроек колонки. Пароль SOCKS не сохраняется в нём и не отдаётся в панель.

Исходники — `src/`, SDK и протокол — [docs/PLUGINS.md](../../docs/PLUGINS.md).
Сборка: `go run scripts/pack-plugins.go build/release` из корня репозитория.
Она создаёт отдельные архивы для ARM64 и ARMv7. Для обычных тестов: `cd plugins/vpn/src && go test ./...`.
Тест настоящего туннеля включается переменной `JARVIS_VLESS`; не публикуйте её значение и не сохраняйте в репозиторий.

Атрибуции зависимостей Xray перечислены в `THIRD_PARTY.md` и `LICENSES/` в корне проекта
и распространяются в архиве `THIRD_PARTY_NOTICES.tar.gz` рядом с файлами релиза.
