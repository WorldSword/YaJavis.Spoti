# Home Assistant — модуль Rust

Исходники: `jarvis/modules/homeassistant/`. Это отдельная библиотека, не зависящая
от ядра и Go. В сборку входит только при выборе Cargo feature `homeassistant`.
Lua-плагины и встроенные модули используют один хост: установка, включение,
выключение и удаление доступны на странице «Плагины».

```sh
JARVIS_FEATURES=homeassistant scripts/rs-build.sh 0.9.71-rs
# Напрямую:
cd jarvis
cargo build --release --target aarch64-unknown-linux-musl --features homeassistant
```

После установки этой сборки модуль появляется в каталоге. Его кнопка «Установить»
использует манифест из самой сборки и не загружает исполняемый файл.
Настройка сервера и долгосрочного токена — через существующий экран Home Assistant.
Совместимы прежние `settings.json`, привязки комнат и голосовые инструменты.
Манифест можно также загрузить ZIP-архивом: в корне должен лежать `plugin.json`.

Поддерживается:

- список устройств, контекст для модели, включение/выключение и состояние;
- пылесос: запуск, пауза, остановка, возврат на базу;
- распознавание коротких команд пылесосу без модели;
- уборка комнаты через script, notify или text с повторным чтением карты;
- поиск комнат и связей устройств через реестр WebSocket;
- свежие подтверждения результата; старый ответ не подтверждает новую команду;
- остановка мойки/сушки базы, связанной с нужным пылесосом;
- отмена текущих HTTP/WebSocket-запросов при выключении модуля.

Отдельный модуль имеет приоритет над Home Assistant из прежнего плагина «Умный дом».
После выключения или удаления выбранного модуля старый провайдер не включается автоматически.
Прежний объединённый плагин остаётся переходным способом работы остальных подключений.

Выключение останавливает модуль. Для удаления его кода и зависимостей из бинарника
нужна сборка без `homeassistant`. Автоматическая пересборка Rust-ядра при выборе
модулей в панели пока не реализована.

Проверки:

```sh
cd jarvis
cargo test --workspace --features homeassistant
cargo test -p jarvis --no-default-features
```

Тесты используют локальный HTTP/WebSocket-сервер и не обращаются к реальному дому.
