# Умный дом

Официальный нативный плагин YaJarvis: Яндекс Умный дом, Home Assistant,
Xiaomi Home и Smart Life. Подключения выбираются независимо в панели.
Один процесс объединяет четыре адаптера, чтобы не хранить на слабой колонке
четыре копии среды Go и не занимать память четырьмя процессами.

В плагине находятся облачные протоколы, QR-вход, обновление токенов,
локальный протокол Tuya, разбор возможностей устройств и уборка комнат.
В ядре остались адаптеры панели и общая маршрутизация голосовых команд.
Штатная Алиса продолжает работать независимо от этого плагина.

Настройки — «Плагины» → «Умный дом» → «Настроить». Старые подключения
сохраняются в настройках колонки; ключи не возвращаются в браузер.
Кеши устройств копируются в данные плагина один раз. Выход из аккаунта
не приводит к повторному импорту старого кеша.

Сборка: `go run scripts/pack-plugins.go build/release` из корня проекта.
Архивы: `plugin-home-arm64.zip` и `plugin-home-armv7.zip`.

Протоколы Tuya и Xiaomi реализованы самостоятельно по открытым материалам,
указанным в [CREDITS](../../CREDITS.md) и [THIRD_PARTY](../../THIRD_PARTY.md).
